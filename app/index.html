Settings

This app publishes to github.com/doubledekr/nmc-rate-desk. The publishing key is a GitHub fine-grained token for that one repo (Contents: read and write). It is stored encrypted on this computer and survives updates.

The topic name is generated once and written into rates.json, so toolkits find it on their own. Change it only if you also want every toolkit to re-read it on its next poll.
